# XU 本地文档工作台：安装与使用

XU 本地文档工作台让公共知识库和你电脑中的个人文档出现在同一个界面中。公共内容仍按原来的方式在线阅读；本地 Word、Excel、PowerPoint、PDF 和 Markdown 文件只在你点击时读取，不会上传到服务器。

## 它如何工作

XU 负责左侧公共资源与“我的资源”、顶部文档标签以及右侧目录和书签。独立下载的 `XU-Office-Editor` 只提供中间文档区域需要的 PDF、Markdown 和 Office 运行能力。

Office 运行组件约 250 MiB，不进入 XU 主仓库，也不会在浏览公共文章时加载。你只需下载一次并保存在电脑的固定位置，之后 XU 会在获得授权后直接从该目录读取。

## 当前本地验证方式

当前功能仍处于两个仓库的本地联调阶段，暂时不需要创建新的远程仓库。

1. 保留完整的 `XU-Office-Editor` 仓库目录。
2. 启动 XU 本地开发页面。
3. 在左侧“我的资源”底部点击“选择组件目录”。
4. 选择 `XU-Office-Editor` 仓库根目录，而不是其中的 `assets` 子目录。
5. 再选择自己的文档文件夹。
6. 点击 Word、Excel、PowerPoint、PDF 或 Markdown 文件，在 XU 中间区域打开。

## 正式发行后的下载方式

正式版本将提供两个内容一致、版本号一致的下载入口：

- 国外及 GitHub 访问顺畅的用户：从 [GitHub 项目](https://github.com/Lucifer-cgl/XU-Office-Editor) 下载发行包；
- 中国大陆用户：从后续公布的 Gitee 镜像下载相同版本的发行包。

下载后请解压到固定位置，例如 `D:\XU-Office-Editor`。首次连接成功后，不要随意删除、移动、改名或拆散目录中的文件，否则 XU 下次将无法找到本地运行组件，需要重新选择或重新下载。

## 文件夹与隐私

运行组件目录和个人文档目录是两个不同的授权：

- 运行组件目录只存放工作台自身文件；
- 个人文档目录存放你需要阅读或编辑的资料；
- XU 只保存浏览器提供的目录句柄；
- 选择个人文档目录时只枚举名称和层级，不读取全部文档；
- 点击具体文件后才读取该文件；
- 保存时只写回当前文件。

建议在 Chrome 或 Edge 的文件权限提示中选择长期允许。如果浏览器清除了站点数据或你主动撤销权限，XU 会要求重新选择目录，但不会删除本地文件。

## 更新组件

后续版本会通过运行组件清单检查版本。更新时优先只替换发生变化的分片；更新失败时保留旧版本，不影响个人文档。更新过程中不要删除个人文档目录，也不要把个人文件放进运行组件目录。

## 当前支持范围

- Word、Excel、PowerPoint 和 OpenDocument：浏览器内阅读、基础编辑与保存；
- PDF：浏览器内只读预览；
- Markdown：阅读、编辑与保存；
- 公共资源和本地资源共用文档标签；
- Markdown 标题可进入右侧目录；Word 大纲、PPT 幻灯片和 Excel 工作表目录将在后续接口中逐步补齐。

本工作台面向“快速打开、查看、修改一点并保存”的高频场景，不以替代 WPS 或 Microsoft Office 的全部高级功能为目标。
