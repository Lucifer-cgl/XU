3. 三种方法核算GDP

生产法（增加值法）

GDP = 所有部门增加值之和

  • 农场：800亿元
  • 面粉厂：500亿元
  • 面包店：1500亿元
  • 中介服务：50亿元（二手交易产生的新服务）
GDP = 800 + 500 + 1500 + 50 = 2850亿元

收入法（要素收入法）

GDP = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 营业盈余

  • 劳动者报酬：农场350 + 面粉厂250 + 面包店700 + 中介50 = 1350亿元
  • 生产税净额：农场80 + 面粉厂40 + 面包店150 = 270亿元
  • 固定资产折旧：农场70 + 面粉厂50 + 面包店100 = 220亿元
  • 营业盈余：农场300 + 面粉厂160 + 面包店550 = 1010亿元
GDP = 1350 + 270 + 220 + 1010 = 2850亿元

支出法（最终产品法）

GDP = 最终消费支出 + 资本形成总额 + 净出口

  • 最终消费支出：家庭消费2600 + 中介服务消费50 = 2650亿元
  • 资本形成总额：存货增加200亿元
  • 净出口：0（封闭经济）
GDP = 2650 + 200 + 0 = 2850亿元
