# 第七次作业 第四章习题八与习题九

> [!summary] 来源与范围
> 题目依据《会计学原理_资料.pdf》印刷第334—335页提取；解答依据《第七次作业.docx》整理。习题八为调整分录、丁字形账户和工作底稿；习题九依据习题八的结果编制收益表、结账分录和资产负债表。金额单位为元。

## 题目

### 习题八

**目的：**练习工作底稿的编制。

| 应付票据 | | 36 000 |

| 管理费用 | 7 000 | |
| 财务费用—利息收入 | | 4 500 |
| **合计** | **321 600** | **321 600** |

**资料2：**12月31日应予调整的事项：

1. 本月应计提固定资产折旧9 650元，其中出租的空闲店面折旧费650元。
2. 本年度的预付财产保险费余额全部由本月负担。
3. 本月初将100平方米的空闲店面出租给多利公司，租期暂定3个月，每月租金5 400元，于第二个月中旬一次交付。
4. 预收货款中的7 500元在本月已实现销售。
5. 本月银行存款应计利息为1 300元。
6. 月末应计未付销售人员工资为1 950元。
7. 题目给出：按利润总额的25%计提本月应交所得税7 925元。

**要求：**（1）试作出调整分录；（2）编制工作底稿。

> [!important] 本次作业的补充口径
> 第（1）项折旧按管理费用9 000元、其他业务成本650元分列；第（3）项另计应承担的税金及附加270元；第（4）项另结转销售成本3 000元；第（7）项所得税直接采用题给7 925元，不因新增调整重新计算。以下解答按这些条件填写。
