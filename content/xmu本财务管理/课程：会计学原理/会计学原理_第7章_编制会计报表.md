## 二、两张报表回答不同问题

| 对比 | 资产负债表 | 利润表／课件旧称损益表 |
|---|---|---|
| 看什么 | 某一时点的资源、义务和所有者权益 | 一段期间的经营成果 |
| 时间表述 | 例如12月31日 | 例如本年1月1日至12月31日 |
| 基本依据 | $A=L+E$ | 收入与费用及其他损益配比 |
| 主要数据 | 调整后的账户余额及相关明细 | 相应期间损益发生额或据其汇总的成果 |
| 不能直接推断 | 有资产不等于现金随时可用 | 有利润不等于已收到同额现金 |

第264—273张反复考“时点”与“期间”。把资产负债表写成“某一期间的财务状况”，或把利润表写成“某一时点的利润”，都是混淆。

## 三、报表项目与账户之间怎样衔接

### 1. 常用填列关系

| 报表项目 | 本课的简化填列关系 | 应注意什么 |
|---|---|---|
| 货币资金 | 库存现金＋银行存款＋其他货币资金 | 不是只取银行存款。 |
| 应收账款净额 | 相关债权余额扣相应坏账准备，必要时按明细重分类 | 借贷方向异常时不能机械按总账相抵。 |
| 存货 | 材料采购／在途材料、原材料、在产品生产成本、库存商品等相应成本，扣适用准备 | 本期已售商品成本不再留在存货。 |
| 固定资产净额 | 原值－累计折旧－适用减值准备 | 原值与净额不能同时重复加进资产合计。 |
| 未分配利润 | 年内按本年利润与利润分配相关余额合并；年末结转后看结余 | 本年利润借余为亏损，须扣减。 |
| 营业收入 | 主营业务收入＋其他业务收入 | 不包括营业外收入和股东投入。 |
| 营业成本 | 主营业务成本＋其他业务成本 | 不包括仍在生产成本账户的在产品。 |

来源：第176、267、270—274、288张。表内为本课常见简化关系，具体项目需核实同一截止日及相关明细，不能不加判断把所有正余额一律相加。

### 2. 正常余额与报表位置不是绝对一一对应

第二次作业应付账款实际借余1 500元，试算表放借方；编报时还要按明细和业务性质考虑预付款等重分类。坏账准备和累计折旧虽贷余，仍是资产抵减，不能当作欠外部人的负债。

## 四、利润表的层次：营业利润、利润总额、净利润

按第250、175张课件结构：

$$
\begin{aligned}
\text{营业利润}={}&\text{营业收入}-\text{营业成本}-\text{税金及附加}\\
&-\text{销售费用}-\text{管理费用}-\text{财务费用}-\text{资产减值损失}\\
&+\text{公允价值变动收益}+\text{投资净收益}
\end{aligned}
$$

$$
\text{利润总额}=\text{营业利润}+\text{营业外收入}-\text{营业外支出}
$$

$$
\text{净利润}=\text{利润总额}-\text{所得税费用}
$$

各项都是同一主体、同一期间金额，单位为元；出现净损失时按相应符号扣减。公式按该课件展示项目列出，不是声称包含全部版本、全部企业的现行利润表项目。收入增加提高利润，但相应成本可能也增加；费用增加在其他条件不变时减少利润。

**题目（第269张第37题）：** 增值税50 000、所得税10 000、消费税5 000，没有其他税费，利润表“营业税金及附加”多少？

**解答：** 按题给口径5 000元，选C。增值税不因此列入该损益项目，所得税费用在利润总额之后单列。税额不能因为同样带“税”字就相加到同一栏。

## 六、利润表练习：只选损益，不把存货混进来

**题目（第274张）：** 期末结转前账户如下，计算营业利润、利润总额和净利润。列示原题数据，单位：元。

| 账户 | 借方余额 | 贷方余额 |
|---|---:|---:|
| 生产成本 | 80 000 |  |
| 库存商品 | 200 000 |  |
| 主营业务收入 |  | 1 500 000 |
| 主营业务成本 | 600 000 |  |
| 营业税金及附加 | 75 000 |  |
| 应交税费 |  | 90 000 |
| 管理费用 | 10 000 |  |
| 财务费用 | 5 000 |  |
| 销售费用 | 8 000 |  |
| 应付职工薪酬 |  | 15 000 |
| 其他业务收入 |  | 10 000 |
| 其他业务成本 | 7 000 |  |
| 原材料 | 40 000 |  |
| 所得税费用（原题“所得税”） | 202 750 |  |
| 利润分配 |  | 85 000 |
| 营业外收入 |  | 6 000 |

**解答：** 营业收入$1500000+10000=1510000$；营业成本$600000+7000=607000$。

$$
\text{营业利润}=1510000-607000-75000-10000-5000-8000=805000\text{ 元}
$$

$$
\text{利润总额}=805000+6000=811000\text{ 元}
$$

$$
\text{净利润}=811000-202750=608250\text{ 元}
$$

生产成本、库存商品、原材料是成本或资产结存，不能全从本期收入中扣掉；应交税费和应付工资是负债余额，不等于本期费用；利润分配不是利润形成过程的费用。题给所得税费用直接使用，不重新发明一套税率。

### 5. 题目第二问：能否直接改成截至6月30日的一年报表

**解答：** 不能仅凭目前15个月累计收支与9月末余额可靠拆出截至6月30日的12个月报表。需要7—9月的收支明细、6月末应收应付、存货、预付、应计与折旧等资料。不能把15个月利润简单乘12/15，期间销售和耗费未必均匀。

## 八、报表间关系及解释的边界

净利润通过本年利润、利润分配与未分配利润影响权益，所有者投入和分红也改变权益，因此“权益增加额＝净利润”有额外条件。现金同时受赊销回款、采购支付、设备购建和借款等影响，不能把净利润直接填成现金变动。

本文件未提供系统完整的现金流量表章节和全套编制数据，因此这里只解释其与利润、资产负债表的关系，不凭空制作一套声称源自课件的现金流量表教程。

## 九、章末公式与常见错题

| 公式 | 单位与条件 |
|---|---|
| $A=L+E$ | 同一时点、同一主体，金额单位一致。 |
| 营业收入＝主营业务收入＋其他业务收入 | 同一期间，营业外收入另列。 |
| 营业成本＝主营业务成本＋其他业务成本 | 不混入未完工生产成本。 |
| 净利润＝利润总额－所得税费用 | 同一期间；税额以题给条件为准。 |
| 应收净额＝相关应收余额－坏账准备 | 注意明细重分类与相同债权范围。 |

**题目（第267张）：** 本年利润借余30 000元、利润分配贷余50 000元，月末未分配利润？

**解答：** $50000-30000=20000$元。本年利润借余是累计亏损，不可当正利润加成80 000。

**题目（第265张）：** 什么不直接列入利润表：生产成本、所得税费用、财务费用、管理费用？

**解答：** 生产成本。未完工部分构成存货，不直接全进本期损益。
