## 一 四张财务报表

### 1 资产负债表

资产负债表反映企业在某一特定时点的财务状况，属于**时点数据**，通常采用权责发生制。

最基本的恒等式是：

$$
\text{资产}=\text{负债}+\text{所有者权益}
$$

其中：

- 资产（Assets）：企业控制并预期带来经济利益的资源；
- 负债（Liabilities）：企业承担的现时义务；
- 所有者权益（Owners' Equity）：资产扣除负债后归属于所有者的剩余权益。

资产通常包括货币资金、短期投资、应收账款、存货、长期投资、固定资产净值和无形资产；负债包括短期借款、应付账款、应付职工薪酬、应交税费和长期借款；所有者权益包括投入资本和留存收益。

固定资产净值：

$$
\text{固定资产净值}=\text{固定资产原值}-\text{累计折旧}
$$

### 2 课件资产负债表交易例

企业发生：股东投入 1,000 万元，银行贷款 500 万元，用银行存款购买厂房 800 万元，赊购原材料 200 万元。

交易后的结构：

| 项目     | 资产变化                | 负债或权益变化         |
| ------ | -------------------:| ---------------:|
| 股东投入资本 | 货币资金 +1,000         | 投入资本 +1,000     |
| 银行贷款   | 货币资金 +500           | 长期借款 +500       |
| 购买厂房   | 货币资金 -800、固定资产 +800 | 不变              |
| 赊购原材料  | 存货 +200             | 应付账款 +200       |
| **合计** | **资产 1,700**        | **负债与权益 1,700** |

每一笔交易都必须同时影响资产、负债或权益的至少一项，且恒等式始终成立。

#### 2024年末资产负债表示例

单位：万元。

| 资产 | 金额 | 负债与所有者权益 | 金额 |
|---|---:|---|---:|
| **流动资产** |  | **流动负债** |  |
| 货币资金 | 700 | 短期借款 |  |
| 短期投资 |  | 应付账款 | 200 |
| 应收账款 |  | 应付职工薪酬 |  |
| 存货 | 200 | 应交税费 |  |
|  |  | 应付股利 |  |
| **长期投资** |  | **长期负债** |  |
| 固定资产 | 800 | 长期借款 | 500 |
| 减：累计折旧 | 0 |  |  |
| 固定资产净值 | 800 | **所有者权益（股东权益）** |  |
| 无形资产及其他资产 |  | 投入资本 | 1,000 |
|  |  | 留存收益 |  |
| **资产合计** | **1,700** | **负债与所有者权益合计** | **1,700** |

$$
700+200+800=200+500+1000=1700
$$

### 3 利润表

利润表反映一段期间内的经营成果，属于**时期数据**，通常以权责发生制确认收入和费用：

$$
\text{收入}-\text{费用}=\text{利润}
$$

常见层级：

$$
\text{营业利润}=\text{营业收入}-\text{营业成本}-\text{期间费用}+\text{其他经营损益}
$$

$$
\text{利润总额}=\text{营业利润}+\text{营业外收入}-\text{营业外支出}
$$

$$
\text{净利润}=\text{利润总额}-\text{所得税费用}
$$

其中，营业收入、成本、销售费用、管理费用、财务费用和所得税费用是利润表主要项目。利润表不等于现金流量表，因为收入和费用可能在现金实际收付之前确认。

#### 2025年1月利润表示例

单位：万元。

| 项目 | 金额 |
|---|---:|
| 营业收入 | 150 |
| -营业成本 | 100 |
| -营业税费 |  |
| -销售费用 | 10 |
| -管理费用 | 7 |
| -财务费用 | 3 |
| -资产减值损失 |  |
| +（-）公允价值变动净收益（净损失） |  |
| +（-）投资净收益（净损失） |  |
| **营业利润** | **30** |
| +营业外收入 |  |
| +营业外支出 |  |
| **利润总额** | **30** |
| -所得税 | 10 |
| **净利润** | **20** |

计算关系为：$150-100-10-7-3=30$，$30-10=20$。其中，出售一半存货形成营业收入150万元和营业成本100万元；销售费用10万元为固定资产折旧，管理费用7万元为已支付工资，财务费用3万元为已支付利息，所得税10万元尚未缴纳。

150万元收入虽然尚未收款，但按权责发生制已经确认，因此同时形成150万元应收账款。

#### 2025年1月末资产负债表示例

单位：万元。

| 资产 | 金额 | 负债与所有者权益 | 金额 |
|---|---:|---|---:|
| **流动资产** |  | **流动负债** |  |
| 货币资金 | 490 | 短期借款 |  |
| 短期投资 |  | 应付账款 |  |
| 应收账款 | 150 | 应付职工薪酬 |  |
| 存货 | 100 | 应交税费 | 10 |
|  |  | 应付股利 | 5 |
| **长期投资** |  | **长期负债** |  |
| 固定资产 | 800 | 长期借款 | 500 |
| 减：累计折旧 | 10 |  |  |
| 固定资产净值 | 790 | **所有者权益（股东权益）** |  |
| 无形资产及其他资产 |  | 投入资本 | 1,000 |
|  |  | 留存收益 | 15 |

留存收益增加15万元，而不是20万元：

$$
\Delta RE=NI-Div=20-5=15
$$

其中，$RE$ 是留存收益，$NI$ 是净利润（Net Income），$Div$ 是股利（Dividends）。

### 4 现金流量表

现金流量表反映一段期间内现金和现金等价物的实际流入和流出，属于**时期数据**，采用收付实现制：

$$
\text{现金流入}-\text{现金流出}=\text{净现金流量}
$$

现金流按来源分为：

- 经营活动现金流量（Operating Cash Flow）；
- 投资活动现金流量（Investing Cash Flow）；
- 筹资活动现金流量（Financing Cash Flow）。

#### 2025年1月现金流量表示例

课件将支付利息列入筹资活动；实际分析应以适用准则和企业披露口径为准。

单位：万元。

| 项目 | 金额 |
|---|---:|
| **经营活动现金流量：** |  |
| 现金流入 |  |
| 现金流出 | 207 |
| **经营活动净现金流量** | **-207** |
| **投资活动现金流量：** |  |
| 现金流入 |  |
| 现金流出 |  |
| **投资活动净现金流量** |  |
| **筹资活动现金流量：** |  |
| 现金流入 |  |
| 现金流出 | 3 |

经营活动现金流出207万元包括归还应付账款200万元和支付工资7万元；筹资活动现金流出3万元为支付利息。

### 5 股东权益变动表

股东权益期末余额由期初余额、股东投入、净利润、股利和其他直接计入权益的利得损失共同决定：

$$
\text{期末股东权益}
=\text{期初股东权益}+\text{股东投入}+\text{净利润}-\text{股利}+\text{其他权益变动}
$$

课件例题中：期初权益 1,000 万元，净利润 20 万元，分配股利 5 万元，因此期末权益为：

$$
1000+20-5=1015\text{万元}
$$

单位：万元。

|---|---:|

| 直接计入股东权益的利得和损失 |  |

## 二 报表之间的勾稽关系

四张报表并不是孤立的：

```text
利润表：收入 - 费用 = 净利润
                 ↓
股东权益变动表：净利润 - 股利 = 权益变动
                 ↓
资产负债表：期末资产 = 期末负债 + 期末权益
                 ↑
现金流量表：现金净增加额决定期末货币资金
```

资产负债表现金项目的变化满足：

$$
\text{期末现金}=\text{期初现金}
+\text{经营活动净现金流}
+\text{投资活动净现金流}
+\text{筹资活动净现金流}
$$

其中，三类净现金流合计为本期净现金增加额。

## 三 企业现金流量

### 1 经营现金流

课件给出的企业资产现金流近似表达为：

$$
CF(A)=EBIT+\text{折旧}-\text{税}
$$

更严格地，若税率为 $t$：

$$
CF(A)=EBIT(1-t)+\text{折旧}
$$

其中：

- $CF(A)$：企业资产产生的现金流（Cash Flow from Assets）；
- $EBIT$：息税前利润（Earnings Before Interest and Taxes）；
- $t$：企业所得税税率；
- 折旧：非现金费用，需要加回。

资本性支出为固定资产净增加：

$$
\text{资本性支出}=\text{期末固定资产净额}-\text{期初固定资产净额}+\text{本期折旧}
$$

净营运资本增加额为：

$$
\Delta NWC=\Delta\text{流动资产}-\Delta\text{流动负债}
$$

企业资产现金流的一般形式：

$$
CF(A)=\text{经营现金流}-\text{资本性支出}-\Delta NWC
$$

### 2 对债权人的现金流

$$
CF(B)=\text{利息支付}+\text{偿还到期债务}-\text{新增长期债务}
$$

其中，$CF(B)$ 是对债权人的现金流，新增债务是现金流入，因此在计算现金流出时要扣除。

### 3 对股东的现金流

$$
CF(S)=\text{股利}+\text{股票回购}-\text{新股发行}
$$

其中，$CF(S)$ 是对股东的现金流。新股发行是股东向企业投入资金，因此对企业而言是现金流入，要从支付给股东的现金流中扣除。

财务现金流量恒等式：

$$
CF(A)\equiv CF(B)+CF(S)
$$

这表示企业资产产生的现金最终只能流向债权人或股东。

## 四 现金流量表直接法与间接法

### 1 直接法

直接法按照现金实际收付列示经营活动：

$$
\text{经营净现金流}
=\text{经营现金流入}-\text{经营现金流出}
$$

例如课件案例中的现金流出包括归还应付账款 200 万元和支付工资 7 万元等。

### 2 间接法

间接法从净利润出发，调节非现金项目和营运资本变化：

$$
\text{经营现金流}
=\text{净利润}+\text{非现金费用}
\pm\text{营运资本项目变化}
$$

典型调整：

- 加回折旧，因为折旧减少利润但不减少现金；
- 加回财务费用时要结合现金流分类口径；
- 存货减少通常增加经营现金流；
- 应收账款增加通常减少经营现金流；
- 应付账款增加通常增加经营现金流；
- 应交税费增加表示尚未支付，通常增加经营现金流。

#### 课件间接法调节表示例

单位：万元。

| 调节项目 | 加减方向 | 金额 | 原因 |
|---|:---:|---:|---|
| 净利润 | 起点 | 20 | 权责发生制利润 |
| 加：折旧 | + | 10 | 非现金费用 |
| 加：财务费用 | + | 3 | 按课件口径转入筹资活动 |
| 加：存货减少 | + | 100 | 释放经营资金 |
| 加：应交税费增加 | + | 10 | 费用已确认但现金尚未支付 |
| 减：应收账款增加 | - | 150 | 收入已确认但现金尚未收到 |
| 减：应付账款减少 | - | 200 | 支付以前赊购形成的负债 |
| **经营活动净现金流** |  | **-207** | $20+10+3+100+10-150-200$ |

因此，本期净利润为20万元，但经营活动现金流为负207万元。差异主要来自应收账款增加和归还应付账款。

## 五 财务报表分析方法

### 1 比较分析法

- 历史趋势比较：观察同一企业多期变化；
- 行业竞争地位比较：与同行业企业比较；
- 计划执行效果比较：与预算、目标或标准比较。

### 2 结构分析法

把报表项目转化为同一基数下的百分比：

$$
\text{共同比项目}=\frac{\text{项目金额}}{\text{共同基数}}\times100\%
$$

资产负债表通常以资产总额或负债与权益总额为基数；利润表通常以营业收入为基数。

### 3 比率分析法

比率分析把绝对金额转换为可比较的相对指标，主要覆盖流动性、偿债能力、资产管理效率、盈利能力和市场价值。

## 六 主要财务比率

### 1 短期偿债能力与流动性

流动比率：

$$
\text{流动比率}=\frac{\text{流动资产}}{\text{流动负债}}
$$

速动比率：

$$
\text{速动比率}=\frac{\text{流动资产}-\text{存货}}{\text{流动负债}}
$$

现金比率：

$$
\text{现金比率}=\frac{\text{现金及现金等价物}}{\text{流动负债}}
$$

指标越高通常意味着短期偿债缓冲更大，但过高也可能说明资金没有得到充分利用。

### 2 长期偿债能力

长期偿债能力分析既要看企业**使用了多少债务**，也要看企业的利润和现金流能否承担利息。前者主要通过负债比率衡量，后者主要通过利息保障倍数和现金覆盖率衡量。

#### 2.1 负债比率（Leverage Ratios）

##### （1）资产负债率（Debt Ratio）

$$
\text{资产负债率}
=\frac{\text{总负债}}{\text{总资产}}
=\frac{\text{总资产}-\text{总权益}}{\text{总资产}}
$$

资产负债率表示总资产中由债务资金支持的比例。例如，资产负债率为 $60\%$，表示每100元资产中约有60元来自债权人资金。

##### （2）债务权益比（Debt-to-Equity Ratio）

$$
\text{债务权益比}=\frac{\text{总负债}}{\text{总权益}}
$$

债务权益比直接比较债权人与股东投入企业的资金规模。该比率越高，企业对债务融资的依赖程度通常越高，财务杠杆也越高。

##### （3）权益乘数（Equity Multiplier）

$$
\text{权益乘数}=\frac{\text{总资产}}{\text{总权益}}
$$

根据会计恒等式 $\text{总资产}=\text{总负债}+\text{总权益}$：

$$
\text{权益乘数}
=\frac{\text{总负债}+\text{总权益}}{\text{总权益}}
=1+\frac{\text{总负债}}{\text{总权益}}
=1+\text{债务权益比}
$$

权益乘数表示企业拥有的资产是股东权益的多少倍，反映财务杠杆对资产规模的放大作用。例如，权益乘数为2，表示1元股东权益支撑了2元资产，其余资产主要由负债融资形成。

三项指标观察的是同一资本结构的不同侧面：

| 指标 | 比较关系 | 主要回答的问题 |
|---|---|---|
| 资产负债率 | 总负债／总资产 | 企业资产中有多大比例依靠债务形成？ |
| 债务权益比 | 总负债／总权益 | 债权人资金相当于股东资金的多少倍？ |
| 权益乘数 | 总资产／总权益 | 每1元股东权益支撑了多少元资产？ |

**反映的信息：**负债比率是衡量企业财务杠杆水平和长期偿债能力的核心指标。比率升高通常意味着企业更加依赖债务融资，利息支出压力和财务风险随之上升，债权人的保障程度相对下降；但负债比率过低也可能说明企业没有充分利用财务杠杆。企业在盈利稳定时适度举债，可能提高股东权益报酬率（$ROE$），但杠杆也会同步放大经营下滑造成的损失。

分析负债比率时应注意：

- **行业差异显著**：公用事业现金流相对稳定，通常可以承受较高杠杆；科技企业往往具有轻资产特征，杠杆水平通常较低。
- **警惕表外负债**：经营租赁、担保责任、未决诉讼等潜在义务，可能使实际杠杆高于报表数字。
- **关注资产估值偏差**：资产账面价值可能与市场价值或清算价值存在差异，应结合资产的实际变现能力判断债权保障程度。
- **检查盈利与现金流是否匹配**：高杠杆必须得到稳定盈利和充足现金流支持，否则偿债风险会明显增加。

#### 2.2 利息保障倍数（Interest Coverage Ratio）

$$
\text{利息保障倍数}=\frac{EBIT}{\text{利息费用}}
$$

其中，$EBIT$ 是息税前利润（Earnings Before Interest and Taxes）。该指标表示企业的息税前利润能够覆盖利息费用多少次，数值越高，企业利用经营利润支付利息的安全边际通常越大。

例如，利息保障倍数为6，表示当期息税前利润相当于利息费用的6倍；若只有1.2倍，经营利润稍有下降就可能出现付息压力。

#### 2.3 现金覆盖率（Cash Coverage Ratio）

$$
\text{现金覆盖率}
=\frac{EBIT+\text{折旧}}{\text{利息费用}}
$$

现金覆盖率又称**现金对利息的倍数**。折旧会减少账面利润，但本期通常没有对应的现金流出，因此在 $EBIT$ 的基础上加回折旧，可以从近似现金的角度观察企业可用于支付利息的资金缓冲。

| 比较项目 | 利息保障倍数 | 现金覆盖率 |
|---|---|---|
| 分子 | $EBIT$ | $EBIT+\text{折旧}$ |
| 观察角度 | 账面经营利润对利息的覆盖 | 加回非付现折旧后的近似现金覆盖能力 |
| 一般关系 | 重资产企业可能相对较低 | 重资产企业折旧较高，通常高于利息保障倍数 |

> 现金覆盖率仍然不是实际经营现金流。应结合经营活动现金流量净额进行交叉验证，因为应收账款、存货和应付账款等营运资本变化也会影响企业真正可用于付息的现金。

应用现金覆盖率时应注意：

- 重资产行业折旧金额较大，现金覆盖率通常明显高于利息保障倍数；
- 应结合经营活动现金流量净额验证，避免仅凭账面数据高估偿债能力；
- 计算利息负担时应关注资本化利息，避免低估企业实际承担的利息成本。

### 3 资产管理效率

总资产周转率：

$$
\text{总资产周转率}=\frac{\text{营业收入}}{\text{平均总资产}}
$$

存货周转率：

$$
\text{存货周转率}=\frac{\text{营业成本}}{\text{平均存货}}
$$

平均收账期：

$$
\text{平均收账期}=\frac{365}{\text{应收账款周转率}}
$$

其中，周转率越高通常代表资产使用效率越高；平均收账期越短通常代表应收账款回收越快。

### 4 盈利能力

销售净利率：

$$
\text{销售净利率}=\frac{\text{净利润}}{\text{营业收入}}
$$

资产收益率：

$$
ROA=\frac{\text{净利润}}{\text{平均总资产}}
$$

股东权益报酬率：

$$
ROE=\frac{\text{净利润}}{\text{平均股东权益}}
$$

其中，$ROA$ 是 Return on Assets，$ROE$ 是 Return on Equity。

### 5 EBITDA

$$
EBITDA=EBIT+\text{折旧与摊销}
$$

EBITDA 是息税折旧摊销前利润（Earnings Before Interest, Taxes, Depreciation and Amortization），用于观察经营现金创造能力，但不等于经营现金流，也不能替代完整现金流量分析。

### 6 市场价值指标

市盈率：

$$
\text{市盈率}=\frac{\text{每股市价}}{\text{每股收益}}
$$

市净率：

$$
\text{市净率}=\frac{\text{每股市价}}{\text{每股账面价值}}
$$

企业价值：

$$
EV=\text{股权市值}+\text{有息负债}-\text{现金}
$$

其中，$EV$ 是 Enterprise Value，反映收购企业经营资产所需承担的净价格。

## 七 杜邦分析

### 1 三因素分解

从净利润除以股东权益出发：

$$
ROE=\frac{\text{净利润}}{\text{股东权益}}
$$

乘以并除以营业收入和资产：

$$
ROE
=\frac{\text{净利润}}{\text{营业收入}}
\times\frac{\text{营业收入}}{\text{总资产}}
\times\frac{\text{总资产}}{\text{股东权益}}
$$

因此：

$$
ROE=\text{销售净利率}\times\text{总资产周转率}\times\text{权益乘数}
$$

其中：

- 销售净利率反映单位收入的盈利能力；
- 总资产周转率反映资产创造收入的效率；
- 权益乘数反映财务杠杆水平。

### 2 与 ROA 的关系

$$
ROA=\text{销售净利率}\times\text{总资产周转率}
$$

$$
ROE=ROA\times\text{权益乘数}
$$

权益乘数为：

$$
\text{权益乘数}=\frac{\text{总资产}}{\text{股东权益}}
$$

## 八 易错点与分析顺序

1. 资产负债表是时点数据，利润表和现金流量表是时期数据。
2. 权责发生制下的净利润不等于现金流；分析现金时必须回到现金流量表。
3. 折旧减少利润但不直接减少现金，因此间接法需要加回折旧。
4. 流动比率高不一定代表经营效率高，还要结合存货周转和应收账款回收速度。
5. ROE 上升可能来自利润率提升、资产周转加快，也可能来自杠杆提高，不能只看一个结果指标。
6. EBITDA 不是现金流，资本性支出和营运资本变化仍需单独扣除。

建议分析顺序：

```text
先看收入与利润趋势
      ↓
再看现金流是否支持利润
      ↓
检查流动性与长期偿债能力
      ↓
分析资产周转和盈利能力
      ↓
用杜邦分析定位 ROE 变化来源
```

## 十 自测题

1. 为什么资产负债表的资产必须等于负债加所有者权益？
2. 为什么净利润为正的企业仍可能出现经营现金流为负？
3. 解释直接法和间接法计算经营现金流的区别。
4. 某企业销售净利率提高但 ROE 下降，可能有哪些原因？
5. 已知净利润 100、营业收入 1,000、平均总资产 2,000、平均股东权益 800，计算销售净利率、资产周转率、权益乘数和 ROE。

### 自测题5参考答案

$$
\text{销售净利率}=100/1000=10\%
$$

$$
\text{总资产周转率}=1000/2000=0.5
$$

$$
\text{权益乘数}=2000/800=2.5
$$

$$
ROE=10\%\times0.5\times2.5=12.5\%
$$
