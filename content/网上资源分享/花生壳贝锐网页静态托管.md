# 花生壳贝锐网页静态托管

Auth: Lucifer

**花生壳 Drop（贝锐网页静态托管）** 是由国内知名的内网穿透与网络服务提供商——贝锐（Oray）推出的**极简静态网站/文件托管工具**。它的核心定位是“免配置、免部署、一键拖拽即可把本地 HTML/静态网页生成公网可访问链接”。

```text
https://hsk.oray.com/drop/ 
```
---

## 一、 产品功能介绍

花生壳 Drop 主要解决个人开发者、设计师、前端工程师或普通用户在**需要快速将本地网页或静态文件分享给他人**时的繁琐问题。

* **拖拽即上线**：无需租用服务器，无需搭建 Nginx/Apache 环境，只需打开浏览器页面，将本地的 HTML 文件、CSS/JS 资源或包含完整网页结构的压缩包**直接拖入上传框**，系统便会在几秒钟内自动部署并生成一个可外网访问的 URL 链接。
* **支持 CLI 与 AI 智能体发布**：除了网页端直接拖拽，它还支持通过命令行工具（`hsk-cli`）或者搭配 AI Agent（智能体）使用，可以用一句指令直接将本地代码打包托管上线。

## 二、 核心优势

### 1. 免去繁琐的域名备案流程（无需手动备案）

在国内部署网站，通常需要购买云服务器、购买域名，并进行长达数天甚至数周的 ICP 备案流程。

* **免备案直连**：花生壳 Drop 依托于贝锐官方已经完成备案且符合合规要求的二级域名系统（如 `*.ficp.fun`）。
* **即即刻访问**：用户上传文件后生成的公网链接直接套用官方合规域名，**完全不需要用户自己去提交 ICP 备案材料**，大大缩短了网页上线的准备周期。

### 2. 提供国内免费公网链接

* **国内节点加速**：相比于海外的免费静态托管平台（如 GitHub Pages、Vercel、Netlify 等在中国大陆时常遭遇网络波动或访问缓慢的情况），花生壳 Drop 基于贝锐在国内的优质节点与 CDN 加速，**国内访问速度快且稳定**。
* **免费体验额度**：平台为免费用户提供了额度（如同时托管 2 个免费公网链接资源），无需支付服务器费用即可轻松测试与展示。

### 3. 极低门槛，免安装软件

* 传统的花生壳服务通常需要下载客户端并进行复杂的端口映射配置。
* 花生壳 Drop 直接在网页端（或通过在线工具）运行，**无需在电脑上安装任何软件或客户端**，用完即走，极其轻量。

### 4. 账号领回与持续管理

* 匿名上传生成的临时链接在登录/认领至个人贝锐账号后，可以进行持久化管理、查看访问统计以及更换自定义的前缀域名。

## 三、 适用场景

1. **前端与 UI 设计效果演示**：写好了一个静态网页、H5 页面或 Prototype 原型，需要立刻发给客户或同事查看。
2. **个人作品集展示**：学生、程序员展示个人简历、项目 Demo 或静态博客。
3. **临时文件/数据报告分享**：通过网页形式打包分享说明文档、数据分析报告等静态文件。
4. **AI 智能体一键发布**：配合命令行工具（`hsk-cli`），让 AI 助手直接帮你把生成的网页代码一键部署并输出公网访问地址。
