# Markdown 排版示例

这篇文章用于验证知识库的 Markdown 转换流程。新增或修改本文后，课程目录和搜索索引都会在构建阶段自动更新。

## 数学公式

行内公式可以写成 $PV=\frac{FV}{(1+r)^n}$，并继续与中文段落自然混排。

独立公式会单独显示，并在窄屏中局部滚动：

$$
NPV=\sum_{t=0}^{n}\frac{CF_t}{(1+r)^t}
$$

## 三线表

所有 Markdown 表格都会统一显示为三线表，不需要在文章中编写额外样式。

## 引用与代码

> 内容与展示分离：Markdown 保存知识，主题负责排版。

```text
content/
└── 课程名称/
    ├── course.json
    ├── 01-第一章.md
    └── assets/
```

### 使用建议

1. 每篇 Markdown 只写一个一级标题。
2. 文件名前使用两位或三位编号控制章节顺序。
3. 图片放在对应课程的 `assets` 文件夹中，并填写替代文本。
